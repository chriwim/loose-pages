Instructor Guide: Expected Accessibility Findings

Use this section after participants have run their accessibility audits.

  1. Missing alternative text

    WCAG 1.1.1 – Non-text Content (Level A). The hero image has no alt attribute.

    axe: image-alt WAVE: Missing alternative text
  2. Vague link text

    WCAG 2.4.4 – Link Purpose (In Context) (Level A). "Click here" does not communicate the destination.

    Manual review
  3. Insufficient color contrast

    WCAG 1.4.3 – Contrast (Minimum) (Level AA). The pale gray text against the light background has insufficient contrast.

    axe: color-contrast WAVE: Contrast
  4. Incorrect heading hierarchy

    WCAG 1.3.1 – Info and Relationships (Level A). The page jumps from H2 to H4 without an H3.

    Manual review
  5. Non-semantic interactive element

    WCAG 2.1.1 – Keyboard (Level A). A clickable div does not provide native keyboard interaction or button semantics.

    Manual keyboard test
  6. Missing form label

    WCAG 1.3.1 and 3.3.2 – Info and Relationships / Labels or Instructions. The email input has only a placeholder.

    axe: label WAVE: Missing form label
  7. Empty button

    WCAG 4.1.2 – Name, Role, Value (Level A). The submit button has no accessible name.

    axe: button-name WAVE: Empty button

Discussion: Which issues were detected automatically? Which required manual testing? Did the tools report the same results?
