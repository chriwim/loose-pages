How the numbers are calculated
  • Speed. WPM = ((|T| − 1) / S) × 60 / 5, where |T| is the length of the transcribed text, S is the time in seconds from the first keystroke to Enter, and a word is five characters. The first character is excluded because its time cannot be measured.
  • Uncorrected errors. INF is the minimum string distance (MSD) between the presented phrase P and the submitted text T. Comparison is case-sensitive and uses the raw strings.
  • Corrected errors. IF counts characters that were entered and later deleted. The page logs every insertion and deletion, so IF = characters entered − |T|. C = |T| − INF.
  • Rates. CER = IF / (C + INF + IF). UER = INF / (C + INF + IF). TER = (INF + IF) / (C + INF + IF). All are shown as percentages. KSPC in the CSV is (entered + deleted) / |T|.
  • Summary. Means and sample standard deviations are taken over test phrases only. Edits are measured by comparing the field before and after each change, so a multi-character deletion counts as that many deleted characters.
  • Sources. Phrase set: MacKenzie and Soukoreff, “Phrase sets for evaluating text entry techniques,” CHI 2003 Extended Abstracts. Error metrics: Soukoreff and MacKenzie, “Metrics for text entry research,” CHI 2003.
