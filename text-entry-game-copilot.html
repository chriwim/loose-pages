Meteor Words

A text entry experiment. Meteors fall toward the city, each carrying an English word. Type a word to destroy its meteor. If every building is destroyed, the game is over. Entry speed and error rates are measured throughout.

How to play

Type with a physical keyboard. Letters appear in the buffer at the bottom; the word explodes the moment it is complete (no Enter needed). Backspace deletes a character, Esc clears the buffer. Characters that do not continue any word on screen count as errors.

Session setup

The same seed with the same settings yields the same word order, useful for comparing conditions. A 3-second countdown precedes each game.

Paused

Words are hidden while paused. The clock is stopped.
